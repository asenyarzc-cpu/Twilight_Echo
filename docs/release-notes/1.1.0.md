# Twilight Echo 1.1.0

**2026-08-26 · 基线 v1.0.5**

1.1.0 相对 1.0.5 累计 190 次提交、686 个文件变更。这一轮的重点是三件事：把界面材质与歌词
渲染做成完整的系统、把 Windows 侧的系统集成与音频引擎稳健性补齐、以及一次大规模的性能与
架构清理。

> [!IMPORTANT]
> 升级前建议备份设置与歌单（设置 → 备份与重置）。Windows 10/11 是唯一完成验证的平台。

---

## 亮点

### 液态玻璃材质系统

播放栏、卡片、歌词面板、侧边栏现在统一走一套"液态玻璃"表面材质，而不是各处零散的
`backdrop-filter`：

- 基于 SVG 位移贴图的**真折射**，边缘会按厚度弯曲背景内容，而非单纯模糊。
- **镜面高光**跟随指针移动，按压时有独立的形变反馈。
- **明暗自适应**：材质会根据背后实际内容的亮度调整透明度、饱和度与高光强度，不再出现浅色
  背景上糊成一团、深色背景上发白的情况。
- 设置 → 外观里提供完整调参（模糊半径、厚度、折射强度、高光、饱和度），也可以整体关闭回退
  到不透明表面。

### 歌词渲染重制

- **新增 AML/TTML 歌词支持**（Apple Music 风格的逐词 TTML）：逐词计时、对唱与和声声部
  （`x-bg` 背景声部按自己的时间区间独立进出）、翻译与音译分层。
- 逐行**弹簧动画 + WAAPI** 驱动的滚动与缩放，替换掉原先的逐帧 JS 布局写入；播放期不再有
  每帧 layout thrash。
- 歌词外观自定义器内嵌进 HiFi 侧边栏，支持外观预设、字体选择器（读取系统已安装字体族）、
  对齐方式与共享样式变量。
- 桌面歌词独立的字体设置。
- 歌词文件解码支持 **UTF-8 (含 BOM) / GBK / GB18030**，解码失败直接拒绝而不是产出 `U+FFFD`
  乱码；同一套解码器也用于外挂 LRC 懒加载与 SACD ISO 同名歌词扫描。

### 播放栏形态与可见性

- 新增**迷你胶囊形态**（无进度条）与紧凑扁平条表面，在播放页自动隐藏。
- 可见性建模为**三档设置**（常显 / 自动隐藏 / 完全隐藏），并按页面作用域分别生效。
- 歌曲列表右键菜单新增"下一首播放"与跳转歌手 / 专辑。
- 引导向导新增**播放器步骤**，首次启动即可配置播放栏形态与迷你播放器偏好。

### Windows 系统集成

- 新增 **SMTC 原生模块**（`audio-engine/smtc`，含 MSVC 工具链脚本与自检），系统媒体控件的
  曲目信息、封面与传输控制走原生实现。
- **任务栏缩略图按钮**（上一曲 / 播放暂停 / 下一曲）与图标生成。
- **全局快捷键可自定义绑定**，"上一曲"按钮行为可选重播当前曲或切上一曲。
- **窗口关闭行为可选**：直接退出 / 最小化到托盘 / 最小化为迷你播放器。
- 任务栏缩略图按钮可整体关闭；迷你播放器支持选择是否在任务栏显示。

### DSD 与音频输出

- DSD 播放改由**专用 ASIO 后端 / 设备**承载，与 PCM 输出路径解耦。
- 24-bit 源按**有效位数**判定直通：只有 24-in-32 的独占设备会走直通，其余不再无谓回落
  float32。
- DSP 主开关状态由各模块状态推导，音量以已保存值为准，避免启动时被临时状态顶掉。
- 均衡器编辑经共享 DSP store 实时生效，修复提交后不落盘的问题。

## 在线音乐与插件

**网易云音乐**

- 播放地址内存缓存加 **20 分钟 TTL**，过期自动重新解析。
- 播放后段**预取下一首地址**交给原生队列携带，过期即剥离重解析，切歌更快。
- 歌曲缓存命中走内存索引，去掉每次播放的整目录扫描；缓存改**流式落盘 + `.part` 原子改名**，
  目录带 LRU 容量上限。
- 上游请求出口加 **5 req/s 令牌桶限速**（时钟回拨时原地重置，不会挂死）；播放地址回退阶梯
  加步间退避，命中风控提示即时早停。
- 新解析会抢占旧的缓存下载，并延迟 30s 启动，连续切歌不再抢带宽。
- 歌单封面请求更高分辨率版本。
- 修复歌手页跳转：改用 provider 歌手 UID，同名歌手不再跳错。

**插件系统**

- 新增**插件开发者模式**与自定义下载目录。
- 新增 provider **下载管理器**：进度按 250ms / 1% 节流，终态任务保留最近 50 条。
- `@twilight-echo/plugin-api` 补齐宿主已支持但未暴露的 **11 个 provider 方法**，并加类型锁
  防止再次漂移。
- 插件启动按依赖层级**分波并行**；插件日志按 1 MiB 轮转并串行化追加写。
- 插件设置改原子写盘。

## 性能

播放期与大库场景是这一轮的主要目标：

- **渲染**：本地库网格窗口化并收敛卡片绘制；流式曲目列表改用队列虚拟窗口；消除播放期每帧
  布局写与周期性全库重排；布局动画期间抑制播放栏模糊重绘；共享歌词行样式对象；缓存自动隐藏
  滚动条的可滚动祖先。
- **状态**：`playlists` / `visualizationData` 改 `shallowRef`，跳过深度代理；歌单事务削减深
  拷贝并改结构化相等比较；共享曲目归一化搜索索引与解析器身份缓存。
- **持久化**：歌单快照剥离歌词全文 / `bpmAnalysis` / `metadataMatch`（都是可重算的派生缓存），
  加载旧文档时即时归一；换曲会话写盘合并为一次防抖。
- **主进程**：协议资产 LRU 缓存、封面 `immutable` 响应头、分析池并发上限与 deadline；
  audioEngine IPC 同步注册前置，引擎初始化转后台并经 ensure 桥接；窗口启动前置。
- **有界化**：`nativeSourceToTrackId`、流媒体滚动位置缓存、歌词 baselines 与加载计数器全部
  封顶，换曲保留最近环。
- 暂停态原生轮询降频。

## 稳定性与修复

**原生音频引擎**

- 修复 `-UNDEBUG` 后暴露的 6 个 ctest 失败，以及卷积器实时路径的 bypass 缺陷。
- 修正 DoP 字节序、float32 输出钳位与 ASIO xrun 处理。
- 收敛 ASIO 启停竞态与异常驱动的缓冲协商；修复 `close()` 超时导致的资源泄漏与挂死。
- WASAPI 独占线程改高精度定时与可中断恢复。
- 传输操作互斥串行化，渲染线程防抖。
- 修正 DST 帧图位宽，加固 SACD 解复用边界。
- 随机播放追加曲目时保持当前播放项稳定。

**播放**

- 列表循环 / 随机在委托原生队列时于**队尾回绕**，去掉等于歌单长度的自动播放上限；
  `listLoop` 与 `shuffle` 现在统一映射到原生 `listLoop`，`upcoming()` 一并回绕以保住
  gapless。随机序列在一次会话内稳定，过队尾重播同一顺序而不重新洗牌。
- 稳定 Windows 路径、IPC 克隆与歌词时钟。
- 启动渲染进程 HTMLAudio 播放前先停原生引擎。
- 修复拖动进度条：seek 只在队列加载进行中才延迟到恢复后执行，其余情况即时生效。
- 音频服务慢方法按分级超时处理，重启带退避；队列加载失败可回滚。
- macOS 队列编号解析修复。

**其他**

- 收藏去重改按**录音身份**判定，同名同歌手的不同录音不再互相顶掉。
- 阻止把图片和元素拖出应用窗口。
- 设置页赞助二维码与默认封面改按 `file://` 渲染进程相对路径加载。
- 设置页折叠对齐、全局字体跟随主题、队列添加歌单、歌词滚动位置修复。
- 本地库壁纸改为在窗口 body 表面**整幅连续绘制**，不再被面板切出接缝。
- 歌词行不再参与全局按压反馈，避免播放页歌词被误加按压动效。

## 架构与工程质量

面向可维护性的一轮集中整理，对使用没有直接可见变化，但决定了后续迭代速度：

- **单一事实源**：IPC 通道常量、跨进程契约类型、音频格式与缓存目录常量下沉到 `src/shared`，
  消除三向手工复制；解除 security 模块的反向依赖。
- **进程边界**：新增导入边界 lint 与 **IPC 通道基线 gate**（`docs/audit-evidence/
ipc-channel-baseline.json`），通道增删必须显式更新基线。
- **拆分**：preload 按域拆成 12 个模块；设置页拆成 10 个分区组件；播放 store 拆成域控制器
  （播放时钟、可视化轮询、睡眠定时、播放历史）；主题目录拆成 token / preset 模块；
  DSP 机架与均衡器页、流媒体页面板与下载逻辑分离。
- **归位**：插件宿主与音频处理移入所属域目录；删除 `usePlaybackQueueStore` 兼容别名。
- **测试与门禁**：渲染进程测试纳入 web typecheck 并补齐类型化 fixture；新增液态玻璃、
  `backdrop-filter` URL 探针、IPC 通道一致性等门禁；恢复完整校验流程。
- **CI**：新增 `audio-engine.yml` 工作流（vcpkg FFmpeg 构建，安装 nasm/yasm），macOS zip
  产物构建改稳。
- 新增 `docs/agent-architecture-guide.md`、`docs/architecture-maintainability-action-plan.md`、
  `docs/structure-review-2026-08-15.md` 等架构文档。

## 已知限制

- **平台**：Windows 10/11 为唯一完成验证的平台。macOS 与 Linux 后端已有实现，但未达到发布
  验证标准。
- **液态玻璃开销**：真折射依赖 SVG filter，在集显或高分屏多窗口场景下有可见 GPU 开销。若
  播放栏拖动不跟手，可在设置 → 外观里降低模糊半径或整体关闭材质。
- **Apple Music provider**：本轮只落地了设计文档与 provider 下载管理器等前置能力，接入本身
  未包含在此版本中。
- **AML/TTML**：仅支持解析与渲染，暂无编辑器侧的写出能力。
- **ASIO 跨编译器 ABI 验证**：本机构建环境缺少 VS 2022 Build Tools，`test:asio-cross-abi`
  未在本轮打包中执行，该证据项如实报告为未运行（而非以其他方式冒充通过）；冻结的 ABI 契约与
  真机验证要求不受影响。

## 升级与回滚

- 从 1.0.5 直接升级：新增设置项会在首次启动时按默认值归一化，无需手动处理。
- 歌单快照在本版本首次加载时会被瘦身重写（剥离可重算的歌词 / BPM / 元数据匹配缓存）。若回退
  到 1.0.5，歌单本体不受影响，这些派生数据会在使用时重新解析或重算。
- 播放会话（续播位置）格式兼容，`heart` 模式一如既往不写入持久化设置。
